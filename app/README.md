# Система управління студентами

Навчальний застосунок курсу «Тестування та супровід програмного забезпечення» (ОК12): консольний облік студентів академічної групи та їхніх оцінок за шкалою ECTS, дані зберігаються у `data/group.json`. Застосунок розвиватиметься разом із курсом: REST API, вебінтерфейс і база даних з’являться до відповідних лабораторних робіт.

Код навмисно не ідеальний: його рецензують, аналізують і тестують на лабораторних роботах.

## Запуск

Потрібен [uv](https://docs.astral.sh/uv/); потрібну версію Python він установить сам.

```bash
cd app
uv run student-portal      # консольний застосунок
uv run student-portal-dean # консоль деканату: імпорт студентів, статуси, стипендії, нагадування
uv run pytest              # тести
uv run ruff check .        # лінтер
```

## Структура

```
app/
├── data/group.json            # приклад даних групи
├── data/students-import.csv   # приклад файлу імпорту студентів (вимога Р-19)
├── src/student_portal/
│   ├── grades.py              # Grade, шкала ECTS (вимога Р-05)
│   ├── corrections.py         # виправлення оцінки (вимога Р-08)
│   ├── people.py              # Person, Student, Teacher
│   ├── status.py              # статус студента (вимога Р-18)
│   ├── scholarship.py         # академічна стипендія (вимога Р-17)
│   ├── group.py               # Group: пошук, рейтинг, статистика
│   ├── storage.py             # збереження у JSON
│   ├── importer.py            # імпорт студентів із CSV (вимога Р-19)
│   ├── reminders.py           # нагадування про заборгованість (вимога Р-20)
│   ├── exceptions.py          # власні винятки
│   ├── cli.py                 # консольне меню
│   └── dean.py                # консоль деканату
└── tests/                     # тести pytest
```

## Нагадування боржникам

Пункт 6 консолі деканату надсилає листи через SMTP, якщо задано змінні середовища `SMTP_HOST` (і за потреби `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`). Без них листи друкуються в консоль.
