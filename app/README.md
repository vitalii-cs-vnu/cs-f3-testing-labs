# Система управління студентами

Навчальний застосунок курсу «Тестування та супровід програмного забезпечення» (ОК12): консольний облік студентів академічної групи та їхніх оцінок за шкалою ECTS, дані зберігаються у `data/group.json`. Застосунок розвиватиметься разом із курсом: REST API, вебінтерфейс і база даних з’являться до відповідних лабораторних робіт.

Код навмисно не ідеальний: його рецензують, аналізують і тестують на лабораторних роботах.

## Запуск

Потрібен [uv](https://docs.astral.sh/uv/); потрібну версію Python він установить сам.

```bash
cd app
uv run student-portal      # консольний застосунок
uv run student-portal-dean # консоль деканату: імпорт студентів, статуси, стипендії, нагадування, звіти
uv run student-portal-api  # вебінтерфейс і REST API на http://127.0.0.1:8000 (документація API: /docs)
uv run pytest              # тести
uv run ruff check .        # лінтер
```

## Нагадування боржникам

Пункт 6 консолі деканату надсилає листи через SMTP, якщо задано змінні середовища `SMTP_HOST` (і за потреби `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`). Без них листи друкуються в консоль.

## Зберігання в PostgreSQL

Модуль `repository.py` (вимога Р-22) зберігає студентів і оцінки в PostgreSQL; ним користуватиметься вебверсія застосунку. Консольні застосунки поки працюють з `data/group.json`.

Тести репозиторію (`tests/test_repository.py`) запускають PostgreSQL 18 в одноразовому контейнері за допомогою Testcontainers, тому потрібен запущений Docker (Docker Desktop, Docker Engine або Podman). Без Docker ці тести пропускаються з поясненням `Docker недоступний`. Перший запуск завантажує образ `postgres:18-alpine` і триває довше.

## REST API

`uv run student-portal-api` запускає REST API (вимога Р-23) на <http://127.0.0.1:8000>; порт змінює змінна `PORTAL_PORT`, файл даних - `PORTAL_DATA` (за замовчуванням `data/group.json`). Інтерактивна документація - <http://127.0.0.1:8000/docs>, схема OpenAPI - `/openapi.json`.

Дані зберігаються в пам’яті процесу: зміни через API не записуються у файл, після перезапуску сервер знову читає `data/group.json`.

Автентифікація - заголовок `Authorization: Bearer <токен>`:

| Токен | Роль |
| --- | --- |
| `admin-token` | адміністратор (деканат) |
| `teacher-token` | викладач |
| `student-1-token`, `student-2-token` | студенти з `id` 1 і 2 |

```bash
curl -H "Authorization: Bearer teacher-token" http://127.0.0.1:8000/api/students
```

Модуль `dean_client.py` - клієнт сервісу деканату (вимога Р-24), який читає з API картку студента.

## Вебінтерфейс

Та сама команда `uv run student-portal-api` відкриває вебінтерфейс (вимога Р-25) на <http://127.0.0.1:8000/>: вхід за токеном з таблиці вище, список студентів з пошуком, додавання і видалення (адміністратор), картка студента з оцінками і формою нової оцінки (викладач). Студент після входу бачить лише власну картку. Сторінка звертається до REST API тим самим токеном; роль повертає запит `GET /api/me`.

Змінна `PORTAL_MAX_DELAY` (секунди) додає до відповідей API випадкову затримку від 0 до цього значення: так імітують повільну мережу під час E2E-тестів.

```bash
PORTAL_MAX_DELAY=0.5 uv run student-portal-api
```

## Звіт про дисципліну

Пункт 7 консолі деканату показує звіт про одну дисципліну групи (вимога Р-26, модуль `course_report.py`): кількість оцінок, середній бал, частку тих, хто склав, розподіл за літерами ECTS і боржників.

## Рівні тестів

Тести позначено за тим, що їм потрібно для запуску:

| Позначка | Що потрібно | Приклад |
| --- | --- | --- |
| без позначки | лише Python | `tests/test_grades.py`, `tests/test_api.py` |
| `integration` | Docker (PostgreSQL у Testcontainers) | `tests/test_repository.py` |
| `e2e` | браузер Playwright | тести вебінтерфейсу |

```bash
uv run pytest -m "not integration and not e2e"   # швидкі тести
uv run pytest -m integration                      # з Docker
```

Позначки зареєстровано в `tests/conftest.py`; ключ `--strict-markers` перетворює помилку в назві позначки на помилку запуску. Без Docker інтеграційні тести пропускаються, але в CI (змінна середовища `CI`) відсутність Docker - помилка: пропущений тест не повинен робити конвеєр зеленим.
